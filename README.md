# 🛍️ Galeri Produk

Aplikasi Manajemen Katalog Produk yang dirancang untuk memudahkan pengelolaan inventaris secara digital. Proyek ini merupakan bagian dari pengembangan portofolio sistem informasi berbasis web/mobile.

## ✨ Fitur Utama
* **Manajemen Produk:** Tambah, edit, dan hapus data produk dengan mudah.
* **Kategori & Label:** Pengelompokan produk berdasarkan jenis untuk pencarian yang lebih cepat.
* **Tampilan Responsif:** Antarmuka yang ramah pengguna baik di perangkat desktop maupun mobile.
* **Sistem Login:** Keamanan akses data untuk admin atau pengelola toko.

## 🚀 Teknologi yang Digunakan
* **Framework:** [Laravel / Flutter] *(Sesuaikan dengan teknologi yang kamu pakai)*
* **Database:** MySQL
* **Bahasa Pemrograman:** PHP / Dart
* **UI Style:** Custom Pink Theme Design
